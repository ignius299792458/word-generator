# Word_Generator — Building MLP Language Model

This Word_Generator introduces a neural-network-based character language model that moves beyond the simple bigram approach. Instead of predicting the next character from only one previous character, the model uses a fixed context of several characters, converts them into learned embedding vectors, combines those embeddings, and passes them through a multilayer perceptron (MLP) to produce logits for the next-character prediction. The model is trained using cross-entropy loss, backpropagation, gradient descent, minibatches, and train/dev/test splits, while the embedding table and network weights are learned jointly from data. Conceptually, this is the first major step from count-based language modeling toward modern neural language models: the same general pipeline—tokens → embeddings → neural network → logits → next-token prediction—continues into Transformers and GPT-style LLMs, where the simple MLP context processor is replaced by much more powerful attention-based architectures.
